# Servicio Hefesto
Implementación de bitácora de trabajo y notas para consultores, equipos técnicos o clientes. Cobrar puesta en marcha, estructura inicial de espacios/etiquetas, capacitación y servicio mensual de alojamiento/backup/soporte. Fijar precio según usuarios, almacenamiento y atención requerida.

Diferencia respecto de Biblioteca (Linkding): aquí el contenido principal son notas propias; allí se organizan enlaces. Wiki (BookStack) sirve mejor para manuales estructurados extensos; Memos para captura y consulta frecuente de notas.

Instancia por cliente recomendada; no se vende como ERP ni gestor de secretos. No incluye colaboración en tiempo real añadida por Hefesto ni garantía de permisos de plataformas destino. Memos usa licencia MIT; imagen conservada sin modificar y licencia incluida.
